# ML_Course_HW_Fall2025

Practical and theoretical homework for the Machine Learning course (Fall 2025) taught by Dr. Sharifi-Zarchi, Computer Engineering Department, Sharif University of Technology.

## What's in here

- **PHW1** — polynomial regression and a perceptron implementation on a simulated dataset, plus a Titanic survival classifier as a full walkthrough (data cleaning, feature engineering, model comparison).
- **PHW2** — unsupervised learning: Gaussian Mixture Models and K-Means clustering (including K-Means for image color quantization/segmentation on sample images), and PCA for dimensionality reduction.
- **THW1 / THW2** — theoretical homework (PDF), math derivations and proofs rather than code.

## Tech stack

Python, Jupyter notebooks, NumPy/pandas/scikit-learn/matplotlib.

## Running it

Each practical homework is a self-contained notebook:

```bash
jupyter notebook ML_PHW1_Fall_2025/Regression_and_Perceptron.ipynb
jupyter notebook ML_PHW1_Fall_2025/Titanic/titanic.ipynb
jupyter notebook ML_PHW2_Fall_2025/GMM/GMM.ipynb
jupyter notebook ML_PHW2_Fall_2025/K-Means/K_Means.ipynb
jupyter notebook ML_PHW2_Fall_2025/PCA/PCA.ipynb
```
